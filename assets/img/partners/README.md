# Partner logos

The site currently uses typographic partner marks in `index.html` and `partners.html`.
Drop the official logo files here with these names, then replace the matching
`<span class="partner-logo ...">` block with an `<img>` (see the main README).

| File | Partner | Role | Supplied format |
|---|---|---|---|
| `tinyfish.svg` | TinyFish | Series partner | SVG |
| `goavo.svg` | GoAvo | Platform partner | SVG |
| `google-for-developers.svg` | Google for Developers | Ecosystem partner | SVG |
| `paytm.svg` | Paytm | Ecosystem partner | JPEG → convert to SVG/PNG |
| `devrel.svg` | DevRel | Community partner | SVG |
| `neo4j.svg` | Neo4j | City partner — Delhi | SVG |
| `rezoomex.svg` | Rezoomex | City partner — Pune | PNG |

Use dark/monochrome versions on the paper partner section, or invert white-only
files with CSS `filter: invert(1)`.
